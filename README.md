# 🤖 Instagram Analyzer Telegram Bot

Telegram-бот для детального анализа подписчиков и подписок Instagram без ввода логина и пароля.

---

## 🚀 Возможности
- 🔍 Определение тех, кто **не подписан в ответ**
- 👤 Определение тех, на кого **ты не подписан в ответ**
- 🤝 Подсчет **взаимных** подписок
- 🖼 Генерация красивой **карточки со статистикой** (PNG) для сторис/друзей
- 📄 **Экспорт списков в TXT**
- 🔎 **Поиск конкретного username** среди списков
- ⚡ Поддержка форматов **JSON** и **HTML**
- 🔒 **Полная безопасность:** бот никогда не просит пароль от Instagram, а работает с официальной выгрузкой Meta

---

## 📋 Как получить архив через Центр аккаунтов Meta

### 💻 С компьютера (ПК):
1. Открой **instagram.com** → в левом нижнем углу нажми **☰ Ещё** → **⚙️ Настройки**.
2. В левой колонке нажми на **Центр аккаунтов Meta**.
3. Выбери **«Ваша информация и разрешения»** (Your information and permissions).
4. Нажми **«Скачать вашу информацию»** → **«Скачать или перенести информацию»**.

### 📱 С телефона:
1. Открой **Instagram** → свой профиль → меню **☰** (вверху справа).
2. Нажми **Центр аккаунтов Meta**.
3. Раздел **«Ваша информация и разрешения»** → **«Скачать вашу информацию»**.

---

### Дальнейшие шаги (одинаково для ПК и телефона):
5. Выбери свой аккаунт Instagram.
6. Выбери **«Выборочная информация»** *(чтобы архив не весил гигабайты)*.
7. Отметь галочкой только: ✅ **«Подписчики и подписки»** → нажми **Далее**.
8. Выбери **«Скачать на устройство»**.
9. ⚠️ **КРИТИЧЕСКИ ВАЖНО:**
   - **Диапазон дат:** обязательно смени с «За прошлый год» на **«За все время» (All time)**! *(Иначе скачаются только подписчики за последний год).*
   - **Формат:** **JSON** или **HTML** *(бот принимает оба)*.
10. Нажми **«Создать файлы»**.
11. Через 3–10 минут Meta подготовит архив. Скачай ZIP-файл (он весит меньше 1 МБ) и отправь боту в Telegram!

## 🛠 Локальный запуск

1. Клонируй репозиторий или скачай папку с ботом.
2. Создай файл `.env` на основе `.env.example`:
   ```env
   BOT_TOKEN=твой_токен_от_BotFather
   ADMIN_ID=твой_telegram_id
   ```
3. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запусти бота:
   ```bash
   python bot.py
   ```

## 🌐 Развертывание на Render (Бесплатно 24/7)

Бот полностью подготовлен для бесплатного хостинга **Render.com**.

### Шаг 1. Загрузи проект на GitHub
1. Создай репозиторий на [GitHub](https://github.com) (публичный или приватный).
2. Загрузи файлы проекта в репозиторий (файл `.env` загружать **не нужно**).

### Шаг 2. Создай сервис на Render
1. Зарегистрируйся на [Render.com](https://render.com).
2. Нажми **New +** → **Web Service** *(или Background Worker)*.
3. Подключи свой GitHub-репозиторий с ботом.
4. Настройки:
   - **Name:** `instagram-analyzer-bot`
   - **Region:** любой ближайший (например, Frankfurt)
   - **Branch:** `main` (или `master`)
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
   - **Instance Type:** `Free`
5. В разделе **Environment Variables** добавь две переменные:
   - `BOT_TOKEN` = `твой_токен_от_BotFather`
   - `ADMIN_ID` = `твой_числовой_id`
6. Нажми **Create Web Service**.

> 💡 **Почему Web Service на Free-тарифе работает?**  
> В `bot.py` встроен автоматический легкий веб-сервер проверки здоровья (`health-check`) на порту `$PORT`. Render видит, что порт открыт, не завершает контейнер и держит бота запущенным!
